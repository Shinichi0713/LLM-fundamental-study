ポジショナル・エンコーディングの原理

一言で言えば、「意味のベクトルに、位置を表す固有の『署名』を刻み込むこと」 です。Transformerは並びを意識しないアーキテクチャなので、単語の「順番」という情報を、数学的にベクトルに埋め込む必要があります。

1. 基本的な考え方：足し算の魔法

各単語の埋め込みベクトルを EEE、その位置 pospospos に対応する位置ベクトルを PEPEPE とすると、モデルに入力される値は単にこれらを足し合わせたものになります。

Input=E+PE\text{Input} = E + PE Input=E+PE

なぜ上書きではなく「足し算」なのか。それは、高次元空間において、モデルは意味を抽出する回路と位置を抽出する回路を独立して学習できるからです。足し算によって両方の情報が混ざりつつも、高次元の空間では情報が衝突しにくく、モデルが分離して解読できます。

1. 正弦波（サイン・コサイン）を使う理由

初期のTransformer（"Attention Is All You Need"）では、以下の式で PEPEPE を生成しました。

PE(pos,2i)=sin⁡(pos100002i/dmodel)PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right) PE(pos,2i)​=sin(100002i/dmodel​pos​)

PE(pos,2i+1)=cos⁡(pos100002i/dmodel)PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right) PE(pos,2i+1)​=cos(100002i/dmodel​pos​)

ここで、

  • pospospos：単語の位置（0, 1, 2, 3, ...）
  • iii：ベクトルの次元インデックス
  • dmodeld_{\text{model}}dmodel​：モデルの次元数（例：512）
  • 2i2i2i と 2i+12i+12i+1 でペアになった次元に、それぞれサインとコサインを割り当てる

なぜわざわざ複雑な三角関数を使うのでしょうか？主な理由は2つあります。

① 相対的な位置関係の表現

三角関数には加法定理があります。

sin⁡(a+b)=sin⁡acos⁡b+cos⁡asin⁡b\sin(a + b) = \sin a \cos b + \cos a \sin b sin(a+b)=sinacosb+cosasinb

cos⁡(a+b)=cos⁡acos⁡b−sin⁡asin⁡b\cos(a + b) = \cos a \cos b - \sin a \sin b cos(a+b)=cosacosb−sinasinb

これにより、ある位置 pos+kpos + kpos+k のベクトルは、位置 pospospos のベクトルの線形変換として表現できます。つまり、モデルは「単語Aと単語Bがどれくらい離れているか」を、絶対的な番号ではなく相対的な距離として計算しやすくなるのです。

② 未知の長さへの対応（外挿性）

単に 1,2,3...1, 2, 3...1,2,3... と数値を振ると、学習時よりも長い文章が来たときに数値が巨大になりすぎてモデルが対応できません。周期関数（波）を使えば、値は常に −1-1−1 から 111 の間に収まり、かつ波の組み合わせ（周波数の違い）によって、長い距離でも重複しない固有のパターンを作れます。

3. アナログ時計に例えるとわかりやすい

ポジショナル・エンコーディングの原理は**「時計の針」**に似ています。

  • 短針（低い周波数）：ゆっくり動き、大まかな位置（文のどのあたりか）を示す
  • 長針（高い周波数）：素早く動き、細かい位置（隣の単語との違い）を示す

ベクトル内の各次元が異なるスピードで回転する「針」の役割を果たすことで、すべての「時刻（位置）」をユニークな状態として表現しています。

具体的には、次元 iii が小さいとき（2i/dmodel2i/d_{\text{model}}2i/dmodel​ が小さい）、波長が長くなり「短針」のように振る舞います。逆に次元 iii が大きいとき、波長が短くなり「長針」のように細かい変化を表現します。

4. 進化した原理：RoPE（回転式位置埋め込み）

現在のLLM（Llama 3など）で使われている RoPE（Rotary Positional Embedding）は、この「回転」の概念をより直接的にアテンション計算に取り入れたものです。

原理：単語ベクトルそのものを、位置に応じた角度で 「回転」 させます。

利点：2つの単語のアテンション（内積）を計算したときに、結果が 「2つの単語間の相対的な距離」にのみ依存するようになります。これにより、位置情報の伝達効率が劇的に向上しました。

Sinusoidal PEが「ベクトルに足し算で位置を埋め込む」のに対し、RoPEは「ベクトルを回転させて位置を表現する」という点で、数学的により自然な進化と言えます。

比較

方式 核心的な操作 位置情報の入り方
Sinusoidal PE 位置ベクトルを足し算で追加 絶対位置を波で符号化
RoPE ベクトルを回転させる 相対位置を回転角で符号化

ポジショナル・エンコーディングの本質は、「離散的な順序情報を、連続的かつ幾何学的なベクトル空間に変換する」 ことにあります。三角関数が選ばれたのは、相対位置の表現と外挿性という2つの強力な性質を兼ね備えていたからです。
