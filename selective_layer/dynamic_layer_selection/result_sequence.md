## Section 3.3 の実験内容

- 対象は OPT-1.3B(24層)を Alpaca で調整したモデルです。層数が c = 4, 8, 12, 24 の4モデル(c=24 がフルモデル)を用意します。4モデルのうち3つは、均等に層を飛ばす uniform layer skipping で作ります。
- 各プロンプトに対して4モデルで出力を生成し、ROUGE-L を計算します。
- オラクルは、平均コスト(層数)が予算 β 以下になる条件で、平均 ROUGE-L が最大になるようにプロンプトごとにモデルを割り当てます。これは多選択ナップサック問題で、論文は動的計画法で解いています。
- 結果として、平均 5.6/24 層(23.3%)でフルモデルと同等の ROUGE-L に達しています。そのとき c=4 モデルが69.6%選ばれています。

## Colabでの実験はこう組めます

1. **モデルとデータ**: OPT-1.3B は fp16 で約2.6GBなので T4 に載ります。データは Alpaca を使い、全7800件ではなく500〜1000件程度のサブセットにすれば十分回ります。
2. **層スキップ**: `model.model.decoder.layers` から、論文の式(2)の均等パターンで層を除いたモデルを作ります。1層目は必ず残します。推論のみで、オラクル自体に追加学習は要りません。
3. **生成と評価**: 4モデルで greedy decoding し、`rouge_score` で ROUGE-L を計算します。
4. **オラクル**: コストを4で割ると {1, 2, 3, 6} になるので、numpy で DP を書けます。n=1000 程度なら数秒です。
5. **予算 β を変えて曲線を描く**: 平均 ROUGE-L と各モデルの選択率を、論文の Figure 2 と同じ形で出します。

## 注意点

- **これは実現可能な制御器の性能ではなく、上限の提示です。** オラクルはテスト用の正解 ROUGE を使うので、ばらつきのなかから良い出力を選べてしまいます(論文は Appendix A.5.1 で sampling advantage と呼んでいます)。論文自身も、ベイズ最適を超えていると認めています。したがって、「フルモデルの23%の層で同等」は、そのまま実用で達成できる数字ではありません。
- そのため、論文が使う **greedy oracle**(予算内で各プロンプトごとに最良のモデルを選ぶだけで、予算の融通はしない)も実装して比較するのがよいです。両者の差が、予算配分そのものの効果の目安になります。
- **再現の条件が違います。** 論文は OPT-IML-1.3B を Alpaca で6エポック微調整しています。Colab では `facebook/opt-iml-1.3b` をそのまま使うか、軽い LoRA で済ませることになり、絶対値(論文ではフル 0.342、c=4 で 0.249)は一致しません。傾向が出るかを見る実験と考えてください。
- **プロンプトの扱い**: 論文はプロンプトをフル層で処理し、生成トークンだけ層を飛ばします。簡易版は全体を層削除モデルで処理する形で、実装は楽ですが論文とは少し違います。忠実版は KV キャッシュの扱いが面倒なので、まず簡易版から始めるのがおすすめです。

## 再現できた部分

β=8 では、静的 c=8 が 0.182、greedy oracle が 0.184、random mix が 0.143、oracle が 0.257 でした。

- **sampling advantage は小さい**: greedy が静的 c=8 とほぼ同じなので、「複数出力から良いものを選ぶ効果」だけでは説明がつきません。
- **予算配分の効果は大きい**: oracle は静的 c=8 より +0.075(約4割増)、random mix より +0.114 高いです。
- **混合そのものは損**: random mix が静的 c=8 を下回るのは、深さと品質の関係が上に凸だからだと考えられます。c=4 から c=8 で品質が大きく上がり、その先は伸びが鈍る形です。この損を払ってもなお oracle が上回っているので、配分の効果は本物に見えます。

## 再現できなかった部分

論文では c=4 が69.6%選ばれますが、今回は11.4%です。c=4 モデルの品質が回復しきれていないのが原因だと推測しています。私が読んだ範囲では、論文は6エポックのフル微調整です。こちらは LoRA・2000件・1エポックで、深く削った構成を立て直すには容量も学習量も足りない可能性があります。この推測を確認するため、静的 c=4 と c=12 の ROUGE-L を教えてください。論文では c=4 がフルの約0.73倍です。

## この結果の限界
