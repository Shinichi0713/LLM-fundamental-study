レイヤ選択（層のスキップ・選択）に関する技術は、「入力ごとに動的に選ぶ」ものと「使う層を固定で選ぶ」ものに大別できます。以下は私の知識に基づく一覧です。論文名や公開コードの有無は、実験前に最新状況を確認してください。

## 1. 入力・トークンごとに動的に選ぶ手法

| 技術名 | 概要 | Colab での実験 |
|---|---|---|
| **Early Exit**（DeeBERT、PABEE、FastBERT、CALM など） | 中間層の予測の確信度が十分なら、そこで計算を打ち切る | 小型モデルなら可 |
| **LayerSkip** | Layer Dropout と Early Exit Loss で学習し、自己投機的デコードで高速化する | 先ほどのノートブックで実施済み |
| **Mixture-of-Depths（MoD）** | 層ごとのルータが、トークンごとに「この層を計算するか／スキップするか」を top-k で決める | 公式実装はなし。非公式実装を使うか、小型モデルを自作して学習する |
| **Router-Tuning** | 既存モデルにルータだけを追加で学習し、動的な深さを実現する | ルータのみ学習するので比較的軽い |
| **D-LLM** | トークンごとに、層をスキップするかを動的に決める | 小型モデルなら可 |
| **Mixture-of-Recursions（MoR）** | 層を共有して再帰的に使い、トークンごとに再帰回数を変える | 小規模での事前学習のみ。実装が必要 |
| **Adaptive Computation Time（ACT）、PonderNet、Universal Transformer** | 「何ステップ計算するか」を学習する古典的な手法 | 小型モデルで可 |

## 2. 使う層を固定で選ぶ手法（層の剪定）

| 技術名 | 概要 | Colab での実験 |
|---|---|---|
| **ShortGPT（Block Influence）** | 入出力の類似度が高い層を「冗長」とみなして削除する | 学習不要で、7B を 4bit で読めば可 |
| **層の剪定 + QLoRA で回復**（Gromov ら、"The Unreasonable Ineffectiveness of the Deeper Layers"） | 表現の角度距離が最小になる連続層を削除し、QLoRA で性能を回復させる | 7B でも A100 クラスで可。小型なら T4 でも可 |
| **LaCo、SLEB、LLM-Streamline、FinerCut** | 層の統合や、削除する層の選択基準を改良した手法群 | 論文や実装によっては重い |
| **LayerDrop** | 学習時に層をランダムに落とし、推論時に任意の層数へ後から剪定できるようにする | 小型モデルで可 |

## 3. 層スキップを推論に使う手法

| 技術名 | 概要 | Colab での実験 |
|---|---|---|
| **Draft & Verify**（Self-Speculative Decoding） | 学習不要。スキップする層をベイズ最適化で選び、自分自身を下書きモデルにして高速化する | 7B でも推論のみなので可 |
| **SkipDecode** | バッチ内で、トークン位置に応じてスキップする層を単調に増やす | 実装が必要 |

## 4. 補助的な分析手法

どの層を選ぶべきかを調べるときに使います。

- **Logit Lens / Tuned Lens**: 各層の出力を語彙に射影して、層ごとの予測状況を観察します。先ほどの `exit_generate` もこの一種です。
- **Block Influence、層間のコサイン類似度**: 層の重要度を測る指標です。

## 試す順番のおすすめ

1. **ShortGPT / Gromov らの層剪定**: 学習不要または軽量で、Colab で最も手軽です。小型モデルでも効果を観察できます。
2. **Draft & Verify**: 学習不要で、推論側の効果（高速化）を確認できます。
3. **Mixture-of-Depths の小規模版**: 「トークンごとに層を選ぶ」仕組みを理解するのに適しています。
4. **Router-Tuning**: 既存モデルにルータだけを足して、動的スキップを学習します。

LayerSkip は、1〜2 のような「層の選び方」の研究と、3 のような「選んだ層の使い方」の研究の中間に位置づけられます。

ご希望の手法を教えていただければ、同じ形式の Colab ノートブックを作成します。Colab で最も動かしやすいのは **ShortGPT 系の層剪定**です。
