レーザー高度センサ（レーザー測高センサ、LiDAR高度計）の測定原理について、基礎から応用まで順を追って説明します。

### 1. 基本の仕組み：光の往復時間を測る

レーザー高度センサの最も基本的な原理は、**「レーザー光を地表や対象物に向けて照射し、反射して戻ってくるまでの時間を測定する」** というものです。

光の速さは真空中で約 **299,792 km/s（約30万km/s）** と一定であるため、往復時間を正確に測れば、距離を次の式で算出できます。

```
距離 = (光速 × 往復時間) / 2
```

分母に「2」があるのは、光が「行きと帰り」の距離を往復しているためです。


### 2. 主な測定方式

レーザー高度センサには、用途や精度に応じて3つの主要な測定方式があります。

__(1) パルス方式（Time of Flight: TOF）__

**原理：** ナノ秒〜ピコ秒単位の非常に短いレーザーパルスを発射し、反射光が戻るまでの時間を計測します。

- **特徴：** 数百メートル〜数千メートルの長距離測定に適しています
- **精度：** タイミング計測の分解能に依存。高分解能な計時回路でcm〜mmオーダーの精度が得られます
- **用途：** 航空機搭載LiDAR、衛星レーザー高度計（ICESatなど）、地形測量

__(2) 位相方式（Phase-Shift）__

**原理：** 連続波レーザーを変調（強度変調）して照射し、反射光との位相差から距離を求めます。

```
距離 = (位相差 / 2π) × (変調波長 / 2)
```

- **特徴：** パルス方式よりも高い精度（mmオーダー）が得られますが、測定距離が比較的短いです
- **用途：** 精密測量、建築計測、産業用距離計

__(3) 三角測量方式__

**原理：** レーザー光を対象物に照射し、受光素子（PSDやCCD）で反射光の位置を検出します。照射角度と受光角度の三角関係から距離を算出します。

- **特徴：** 短距離（数cm〜数m）で極めて高精度（μmオーダー）
- **用途：** 工業用センサ、3Dスキャナ、工場の自動検査

### 3. センサの内部構成

典型的なレーザー高度センサは、以下の要素で構成されています。

| 構成要素 | 役割 |
|---------|------|
| **レーザー光源** | 近赤外光（波長900〜1600nm）が一般的。目の安全と大気透過性を考慮 |
| **走査機構** | ミラーや回転機構でレーザーを左右・前後に振り分け、広範囲を計測 |
| **受光光学系** | 反射レーザーを集光するレンズ・ミラー |
| **光検出器** | APD（アバランシェ光ダイオード）やSPAD（単一光子アバランシェダイオード） |
| **タイミング回路** | パルス発射と受光の時間差をピコ秒単位で計測するTDC（Time-to-Digital Converter） |
| **GNSS/IMU** | 航空機・衛星搭載型では、センサ自身の正確な位置・姿勢を記録 |

### 4. 航空機搭載LiDAR（Airborne LiDAR）の動作

地形測量で広く使われる航空機搭載型の場合、以下のように動作します。

1. **レーザー走査：** 航空機の下方に向けて、鏡面回転や振動ミラーでレーザーを左右に振りながら照射（1秒間に数万〜数十万个のパルス）
2. **多重反射の記録：** 1つのレーザーパルスが複数の反射を生む場合があります（樹冠の先端→中間→地面）。これを「複数回波（multi-return）」として記録
3. **位置姿勢の同期：** GNSSで航空機の位置、IMUで姿勢（ロール・ピッチ・ヨー）を記録
4. **点群の生成：** レーザーの方向・距離＋航空機の位置姿勢から、各反射点の地上座標（緯度・経度・標高）を計算

### 5. 測定精度に影響する要因

| 要因 | 影響内容 | 対策 |
|------|---------|------|
| **大気の状態** | 霧、雨、煙がレーザーを散乱・減衰させる | 近赤外波長の選択、強度補正 |
| **地表の反射率** | 暗い表面（アスファルト、水面）は反射が弱い | 高出力レーザー、感度調整 |
| **入射角** | 急斜面ではレーザーが斜めに当たり、足が広がる | 複数回波解析、フィルタリング |
| **複数回波の分離** | 樹冠と地面の反射を区別する必要がある | 高速サンプリング、波形記録（full waveform） |
| **航空機の揺れ** | IMUの精度が標高精度に直接影響 | 高精度IMU、後処理による補正 |


### 6. 衛星搭載レーザー高度計

航空機よりさらに高い軌道上から地表の標高を測定します。

- **例：** NASAのICESat（Ice, Cloud and land Elevation Satellite）は、地球科学用レーザー高度計系（GLAS）を搭載
- **測定高度：** 軌道上から地表まで約600km
- **光点径：** 地上でのレーザー光点は約70m程度
- **用途：** 氷床厚さの変化、森林バイオマス推定、地形測量

衛星の場合、光速が往復約1,200km進むため、往復時間は約 **4ミリ秒**。この極めて短い時間をピコ秒単位で計測することで、標高変化をcm単位で検出します。

### 7. まとめ

レーザー高度センサの本質は、**「光という最も速いものの往復時間を、極めて精密に計測する」**技術にあります。用途に応じてパルス方式・位相方式・三角測量方式が使い分けられ、航空機や衛星に搭載することで、広大な地形の詳細な3Dモデル（点群データ）を生成できます。

この点群データが、先ほどのviewshed分析や3D Tiles変換の元データとして活用されるわけです。
