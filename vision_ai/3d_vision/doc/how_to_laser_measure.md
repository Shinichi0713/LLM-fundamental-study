レーザー高度センサ（レーザー測高センサ、LiDAR高度計）の測定原理について、基礎から応用まで順を追って説明します。

### 1. 基本の仕組み：光の往復時間を測る

レーザー高度センサの最も基本的な原理は、**「レーザー光を地表や対象物に向けて照射し、反射して戻ってくるまでの時間を測定する」** というものです。

光の速さは真空中で約 **299,792 km/s（約30万km/s）** と一定であるため、往復時間を正確に測れば、距離を次の式で算出できます。

```
距離 = (光速 × 往復時間) / 2
```

分母に「2」があるのは、光が「行きと帰り」の距離を往復しているためです。


### 2. 主な測定方式

レーザー高度センサには、用途や精度に応じて3つの主要な測定方式があります。

__(1) パルス方式（Time of Flight: TOF）__

**原理：** ナノ秒〜ピコ秒単位の非常に短いレーザーパルスを発射し、反射光が戻るまでの時間を計測します。

- **特徴：** 数百メートル〜数千メートルの長距離測定に適しています
- **精度：** タイミング計測の分解能に依存。高分解能な計時回路でcm〜mmオーダーの精度が得られます
- **用途：** 航空機搭載LiDAR、衛星レーザー高度計（ICESatなど）、地形測量

__(2) 位相方式（Phase-Shift）__

**原理：** 連続波レーザーを変調（強度変調）して照射し、反射光との位相差から距離を求めます。

```
距離 = (位相差 / 2π) × (変調波長 / 2)
```

- **特徴：** パルス方式よりも高い精度（mmオーダー）が得られますが、測定距離が比較的短いです
- **用途：** 精密測量、建築計測、産業用距離計

__(3) 三角測量方式__

**原理：** レーザー光を対象物に照射し、受光素子（PSDやCCD）で反射光の位置を検出します。照射角度と受光角度の三角関係から距離を算出します。

- **特徴：** 短距離（数cm〜数m）で極めて高精度（μmオーダー）
- **用途：** 工業用センサ、3Dスキャナ、工場の自動検査

### 3. センサの内部構成

典型的なレーザー高度センサは、以下の要素で構成されています。

| 構成要素 | 役割 |
|---------|------|
| **レーザー光源** | 近赤外光（波長900〜1600nm）が一般的。目の安全と大気透過性を考慮 |
| **走査機構** | ミラーや回転機構でレーザーを左右・前後に振り分け、広範囲を計測 |
| **受光光学系** | 反射レーザーを集光するレンズ・ミラー |
| **光検出器** | APD（アバランシェ光ダイオード）やSPAD（単一光子アバランシェダイオード） |
| **タイミング回路** | パルス発射と受光の時間差をピコ秒単位で計測するTDC（Time-to-Digital Converter） |
| **GNSS/IMU** | 航空機・衛星搭載型では、センサ自身の正確な位置・姿勢を記録 |

### 4. 航空機搭載LiDAR（Airborne LiDAR）の動作

地形測量で広く使われる航空機搭載型の場合、以下のように動作します。

1. **レーザー走査：** 航空機の下方に向けて、鏡面回転や振動ミラーでレーザーを左右に振りながら照射（1秒間に数万〜数十万个のパルス）
2. **多重反射の記録：** 1つのレーザーパルスが複数の反射を生む場合があります（樹冠の先端→中間→地面）。これを「複数回波（multi-return）」として記録
3. **位置姿勢の同期：** GNSSで航空機の位置、IMUで姿勢（ロール・ピッチ・ヨー）を記録
4. **点群の生成：** レーザーの方向・距離＋航空機の位置姿勢から、各反射点の地上座標（緯度・経度・標高）を計算

### 5. 測定精度に影響する要因

| 要因 | 影響内容 | 対策 |
|------|---------|------|
| **大気の状態** | 霧、雨、煙がレーザーを散乱・減衰させる | 近赤外波長の選択、強度補正 |
| **地表の反射率** | 暗い表面（アスファルト、水面）は反射が弱い | 高出力レーザー、感度調整 |
| **入射角** | 急斜面ではレーザーが斜めに当たり、足が広がる | 複数回波解析、フィルタリング |
| **複数回波の分離** | 樹冠と地面の反射を区別する必要がある | 高速サンプリング、波形記録（full waveform） |
| **航空機の揺れ** | IMUの精度が標高精度に直接影響 | 高精度IMU、後処理による補正 |


### 6. 衛星搭載レーザー高度計

航空機よりさらに高い軌道上から地表の標高を測定します。

- **例：** NASAのICESat（Ice, Cloud and land Elevation Satellite）は、地球科学用レーザー高度計系（GLAS）を搭載
- **測定高度：** 軌道上から地表まで約600km
- **光点径：** 地上でのレーザー光点は約70m程度
- **用途：** 氷床厚さの変化、森林バイオマス推定、地形測量

衛星の場合、光速が往復約1,200km進むため、往復時間は約 **4ミリ秒**。この極めて短い時間をピコ秒単位で計測することで、標高変化をcm単位で検出します。

### 7. まとめ

レーザー高度センサの本質は、**「光という最も速いものの往復時間を、極めて精密に計測する」**技術にあります。用途に応じてパルス方式・位相方式・三角測量方式が使い分けられ、航空機や衛星に搭載することで、広大な地形の詳細な3Dモデル（点群データ）を生成できます。

この点群データが、先ほどのviewshed分析や3D Tiles変換の元データとして活用されるわけです。

特定の方式（パルス方式の詳細な計時回路、位相方式の変調原理など）について、さらに深く知りたい点があればお知らせください。


パルス方式LiDARにおけるミラーの役割と、センサ内部の構成について説明します。

---

### ミラーの役割：「固定したレーザー」を「動く視線」に変える

パルス方式LiDARでは、レーザー光源自体は**1方向に固定**で発射されます。ミラーはこの固定のレーザービームを**反射させながら方向を変える**ことで、広い範囲にレーザーを走査（スキャン）させる役割を担います。

つまり、**「レーザーを動かすのではなく、ミラーを動かして照射方向を変える」**のが基本です。

---

### 主な走査方式とミラーの種類

#### 1. 振動ミラー（ガルバノミラー）

**仕組み：** モーターでミラーを高速に往復回転させ、レーザーを扇状に振り分けます。

- 往復角度は通常 **±10°〜±30°** 程度
- 1秒間に数十〜数百Hzで往復振動
- 航空機搭載LiDARでは、航空機の進行方向に対して**横断方向（左右）**にスキャンし、航空機自体の前進で縦方向をカバーします

**走査パターン：** 地上ではジグザグ状の線（Zig-Zag pattern）が描かれます。

#### 2. 回転多面鏡（ポリゴンミラー）

**仕組み：** 正多角形（6面〜16面など）の鏡柱をモーターで一定速度で回転させます。

- 各面が順番にレーザーを反射し、1面あたり1本のスキャン線を生成
- 連続回転なので、振動ミラーのような往復の無駄時間がなく、高速・安定した走査が可能
- 航空機搭載LiDARや産業用スキャナで広く使われます

#### 3. 回転式LiDAR（Velodyne方式）

**仕組み：** 複数のレーザー・受光器を**垂直方向に並べたアレイ**を作り、その全体を**水平方向に360度回転**させます。

- 垂直方向は複数のレーザーで一気にカバー（例：16本、32本、64本）
- 水平方向は全体の回転でカバー
- 自動運転車の屋根に見られる「回転カプセル型」がこれに該当

#### 4. MEMSミラー（Micro Electro Mechanical Systems）

**仕組み：** 半導体製造技術で作られた**数mm以下の極小ミラー**を、静電力で傾けます。

- 機械的な回転部が少なく、小型・軽量・高耐久
- 傾き角度は比較的小さい（±5°〜±15°程度）ため、広角には対応しにくい
- 近年の自動車向けLiDARで主流になりつつある方式

#### 5. フラッシュLiDAR（ミラー不要）

**仕組み：** レーザーを1点に集約せず、**広範囲に一斉にフラッシュ照射**します。受光側も2次元アレイ（CCD/CMOSのようなセンサ）で一斉に受光します。

- ミラーや走査機構が不要で、全固体化可能
- 1発のパルスで1枚の「距離画像」を得られる
- ただし、距離が短い（数十m程度）と照射エネルギーが分散するため長距離向きではない

### センサ内部の構成（航空機搭載LiDARの例）

パルス方式LiDARの内部は、大きく**「送信系」**と**「受信系」**に分かれます。

```
┌─────────────────────────────────────────────────────────────┐
│                    LiDAR センサ内部構成                       │
├─────────────────────────────────────────────────────────────┤
│  【送信系】                                                  │
│  レーザー光源 ──→ ビーム整形レンズ ──→ ダイクロイックミラー ──→ 走査ミラー │
│     ↑                                                        │
│  (近赤外LD/固体レーザー)          (送信光と受信光を分離)        │
│                                                               │
│  【受信系】                                                  │
│  走査ミラー ←── 反射光                                         │
│     ↓                                                        │
│  ダイクロイックミラー ←── (送信光と合流するが受信光だけ通過)     │
│     ↓                                                        │
│  集光レンズ ──→ 帯域通過フィルター ──→ 光検出器(APD/SPAD) ──→ TDC │
│     ↑                                                        │
│  (背景光を除去)                  (光→電流→電圧パルス)        │
│                                                               │
│  【補助系】                                                  │
│  GNSS受信機 ──→ 位置記録                                        │
│  IMU(慣性計) ──→ 姿勢(ロール/ピッチ/ヨー)記録                   │
│  制御・記録ユニット ──→ 全データの同期・保存                     │
└─────────────────────────────────────────────────────────────┘
```

#### 各部の詳細

| 部品 | 役割 |
|------|------|
| **レーザー光源** | 近赤外（900〜1600nm）のパルスレーザー。目の安全と大気透過性を考慮。 |
| **ビーム整形レンズ** | レーザーを細い平行光に整える。発散角を制御し、地上での光点径を調整。 |
| **ダイクロイックミラー** | 送信光は反射、受信光は透過する特殊なミラー。送受を同軸に配置できる。 |
| **走査ミラー** | レーザーの照射方向を変える。振動式・回転式・MEMSなど方式は様々。 |
| **集光レンズ** | 微弱な反射光を光検出器に集中させる。口径が大きいほど遠距離の反射光を捉えられる。 |
| **帯域通過フィルター** | レーザー波長のみを通し、太陽光などの背景光を除去。S/N比を向上させる。 |
| **光検出器（APD/SPAD）** | 反射光を電気信号に変換。APDは増幅付き、SPADは単一光子検出が可能。 |
| **TDC（計時回路）** | パルス発射と受光の時間差をピコ秒単位で計測。 |
| **GNSS/IMU** | 航空機搭載型では、各パルスの瞬間の位置・姿勢を記録し、後で地上座標に変換。 |

---

### ミラーが動くことで何が起きるか

航空機搭載LiDARの場合、以下のような動作になります。

1. **ミラーが左右に振れる間**に、数十〜数百発のパルスを発射
2. 各パルスはミラーの角度に応じて**異なる地上位置**に到達
3. 航空機が前進することで、次のスキャン線は**少し先の位置**をカバー
4. 結果として、飛行経路の下に**帯状の点群データ**が生成される

振動ミラーの場合、ミラーの端点で往復する際に速度がゼロになるため、端の方が点が密集し、中央が疎になる傾向があります。多面鏡方式では回転速度が一定なので、走査線上の点間隔が均一になります。

---

### まとめ

| 項目 | 内容 |
|------|------|
| **ミラーの役割** | 固定のレーザービームを反射させ、照射方向を広範囲に走査させる |
| **走査方式** | 振動ミラー、回転多面鏡、MEMSミラー、フラッシュ（ミラー不要）など |
| **内部構成の核心** | 送信系（レーザー→整形→ミラー）と受信系（ミラー→フィルター→検出器→計時回路）を同軸配置 |
| **航空機搭載の場合** | ミラーで横断方向にスキャンし、航空機の前進で縦方向をカバーすることで広域点群を生成 |

ミラーはLiDARにとって「1本のレーザーを、何十万本の視線に増やす」ための不可欠な部品です。走査方式の選択は、測定範囲、速度、耐久性、コストのトレードオフによって決まります。


パルス間隔が短い（＝パルスレートが高い）と精度が向上する理由は、主に**「空間分解能の向上」**と**「統計的ノイズ低減」**の2つに分けられます。ただし、短すぎると別の問題も生じるため、そのトレードオフも含めて説明します。

---

### 1. 空間分解能が向上する（最も大きな理由）

パルス間隔が短いということは、**単位時間あたりに発射するパルス数が多い**ことを意味します。

航空機や衛星が移動しながら計測する場合、パルス間隔が短いほど、**地上での隣接する計測点の間隔（点間距離）が狭くなります**。

#### 具体例

航空機が秒速100m（時速360km）で飛行しているとします。

| パルスレート | パルス間隔 | 地上での点間距離（概算） |
|------------|-----------|------------------------|
| 50 kHz | 20 マイクロ秒 | 約2.0 m |
| 200 kHz | 5 マイクロ秒 | 約0.5 m |
| 1 MHz | 1 マイクロ秒 | 約0.1 m |

パルスレートが4倍になると、同じ飛行速度でも**4倍の密度で点群が得られます**。これにより、より細かい地形の凹凸や建物の形状を正確に捉えられるため、結果として「精度が良い」という実感につながります。

---

### 2. 統計的ノイズの低減

1回のパルス測距には、常に以下のような誤差が含まれます。

- **タイミングジッター**: TDC（計時回路）の分解能による誤差
- **大気の揺らぎ**: 温度・湿度の変動による光速の微小変動
- **受光ノイズ**: 光検出器の暗電流や背景光によるノイズ
- **目標表面の粗さ**: レーザー光点内での反射位置のばらつき

これらは**ランダム誤差（白色ノイズ）**であり、複数回の測定値を平均化することで低減できます。

```
複数パルスの平均距離 = (D1 + D2 + D3 + ... + Dn) / n

ランダム誤差の標準偏差は 1/√n で減少
```

例えば、同じ場所や近接する位置に対して4回のパルスを送れば、誤差は約1/2に。16回なら1/4に低減されます。パルス間隔が短いほど、同じ時間・同じ空間内で**より多くのサンプル**を得られるため、統計的な精度が向上します。

---

### 3. 複数回波の検出確率が上がる

1本のレーザーパルスが樹冠などを貫通する際、複数の反射波（回波）が生じます。パルス間隔が短いと、**樹冠の隙間や地面への「当たり」が増え**、地面標高を正確に捉える確率が上がります。

特に森林や市街地など、遮蔽物が多い環境では、高密度のパルス照射が「見えていない場所」の情報補完に役立ちます。

---

### 4. 移動中の計測で「隙間」を埋める

航空機や車載LiDARでは、センサ自体が移動しながら計測します。パルス間隔が長いと、走査線の間に**計測の隙間（データの空白）**が生じます。

パルス間隔を短くすることで、走査線間のデータが密になり、**地形の連続性をより正確に再現**できます。これは特に急斜面や谷の稜線など、標高変化が激しい場所で重要です。

---

### ただし、パルス間隔を短くしすぎると生じる問題

パルス間隔を無限に短くできるわけではありません。以下の**トレードオフ**があります。

#### 問題1：レンジアンビギュイティ（距離曖昧性）

パルス間隔が短すぎると、**前のパルスの反射光が戻ってくる前に次のパルスを発射してしまい**、どの反射がどのパルスに対応するか分からなくなります。

```
最大測定距離 = (光速 × パルス間隔) / 2
```

| パルスレート | パルス間隔 | 理論上の最大測定距離 |
|------------|-----------|-------------------|
| 100 kHz | 10 μs | 約 1,500 m |
| 500 kHz | 2 μs | 約 300 m |
| 1 MHz | 1 μs | 約 150 m |

衛星搭載LiDAR（地上600km）では、この制約からパルスレートを高くしすぎることができません。地上100mの航空機LiDARなら1MHzでも問題ありませんが、用途に応じた設計が必要です。

#### 問題2：エネルギー密度の低下

パルスレートを上げると、1パルスあたりのレーザー出力エネルギーが減少します（安全規制や装置の発熱制限のため）。反射光が弱くなると、遠距離や低反射率の表面（水面や暗いアスファルト）からの受信が困難になります。

#### 問題3：データ量の増大

高密度の点群は、記録・保存・処理の負荷を増大させます。1MHzのパルスレートで1時間計測すると、数十億点のデータが生成されることになります。

---

### まとめ

| パルス間隔が短い（PRFが高い）メリット | 理由 |
|-----------------------------------|------|
| **空間分解能の向上** | 地上での計測点間隔が狭くなり、細かい地形を捉えられる |
| **統計的ノイズ低減** | 近接点の多数サンプルでランダム誤差を平均化できる |
| **複数回波の検出率向上** | 樹冠や遮蔽物の隙間を通過するパルスが増える |
| **データの連続性向上** | 走査線間の隙間が埋まり、地形再現性が高まる |

| 短すぎる場合のデメリット | 理由 |
|----------------------|------|
| **レンジアンビギュイティ** | 前のパルスの反射が戻る前に次を発射し、距離が曖昧になる |
| **エネルギー密度低下** | 1パルスあたりの出力が減り、遠距離・低反射面での受信が困難に |
| **データ量の増大** | 処理・保存の負荷が増える |

パルス間隔の設計は、**「測定対象の距離」「移動速度」「必要な空間分解能」「処理能力」**のバランスを取ることになります。


メーカーが公表する測定精度（例えば「±2cm」など）は、**表面の凹凸が主な原因というよりは、あくまで「理想的な条件」での装置固有の性能値**です。ただし、実際の現場では表面の凹凸が測定精度を大きく悪化させる主要因の一つになることは確かです。

---

### メーカーの公表精度とは何か

メーカーが謳う精度は、通常以下の条件で測定した値です。

- **垂直入射**（レーザーが対象面に対して真上から当たる）
- **高反射率の平坦面**（白い拡散反射板など）
- **安定した大気条件**（屋内、無風）
- **適正な距離範囲**（規定の測定距離内）

この条件下で、主に以下の装置固有の要因が精度を決定します。

| 要因 | 内容 |
|------|------|
| **TDC（計時回路）の分解能** | パルス発射と受光の時間差をどれだけ細かく測れるか。1ps（ピコ秒）の誤差は約0.15mmの距離誤差に相当 |
| **レーザーパルス幅** | パルスが短いほど時間軸での分解能が高い。ns（ナノ秒）オーダーのパルスでは30cm程度の空間幅 |
| **受光回路の応答速度** | APDやTDCの電気的ノイズ、ジッター |
| **光学系の収差** | レンズの収差や光軸のずれ |

つまり、メーカーの公表値は**「装置が物理的にどこまで分解できるか」**を示しており、表面の凹凸はあくまで「現場での追加誤差」として扱われます。

---

### 表面の凹凸が精度に与える影響

しかし、実際の測定現場では、表面の凹凸が大きな誤差源になります。主に以下の3つのメカニズムがあります。

#### 1. 光点内の高さ分布（フットプリント内の凹凸）

レーザーは地上で**数cm〜数mの光点（フットプリント）**を作ります。この光点の中に複数の高さが含まれると、反射波の波形が広がります。

```
平坦面の反射:  鋭いピーク → ピーク位置を検出しやすい → 精度が高い
凹凸面の反射:  広がった波形 → ピーク位置の判定が曖昧 → 精度が低下
```

例えば、光点径が1mの航空機LiDARが、岩と土が混在する斜面に当たると、反射波形は「岩の高さ」と「土の高さ」の両方からの成分を含み、ピーク検出アルゴリズムによっては中間の高さが出力されます。

#### 2. 反射特性の変化（拡散反射と鏡面反射）

表面の凹凸は反射の仕方を変えます。

- **粗い表面**: 光をあらゆる方向に拡散反射 → 受光器に戻る光は少ないが、安定している
- **滑らかな表面**（水面、氷、金属屋根）: 鏡面反射 → レーザーが受光器に戻らず「データ抜け」が生じる

メーカーの公表精度は拡散反射を前提としているため、鏡面反射的な面では精度どころか**測定不能**になることがあります。

#### 3. 入射角との相互作用

表面が傾いている場合、凹凸の影響はさらに大きくなります。

- 垂直入射では光点はほぼ正円
- 斜め入射では光点は**楕円に歪み**、長軸方向に広がる
- 結果として、より広い範囲の凹凸が「平均化」されて検出され、局所的な高さのばらつきが増大

---

### どの程度の影響か

典型的な数値で比較すると以下のようになります。

| 誤差要因 | 典型的な大きさ |
|---------|-------------|
| メーカー公表精度（装置固有） | ±1cm〜±5cm |
| 表面凹凸による誤差（光点内） | 数cm〜数十cm（光点径と粗さに依存） |
| 入射角による光点歪み | 傾斜45°で約1.4倍の光点拡大 |
| 大気の揺らぎ | 数mm〜数cm（距離・気象条件依存） |

つまり、**平坦なアスファルトやコンクリート面ではメーカー公表値に近い精度が出ますが、樹冠、碎石地、崩壊地などでは表面凹凸の影響が装置精度を上回る**ことがあります。

---

### まとめ

メーカーの公表精度は**「装置自体の限界性能」**であり、表面の凹凸起因ではありません。ただし、それはあくまで「理想的な反射面・垂直入射」という実験室的条件での値です。

実際の現場では、**光点内の凹凸による波形の広がり**が、装置精度以上の誤差を生む主要因となり得ます。特に航空機LiDARのように光点径が大きい（数十cm〜数m）場合、表面の凹凸の影響は無視できません。

したがって、メーカーの公表値を「現場での実測精度」とは考えず、**測定対象の表面性状・入射角・光点径を加味した上で、実際の誤差を現地検証（チェックポイント測量など）で確認する**ことが重要です。


メーカーが「パルスレートが高いほど精度が良い」と謳うのは、**単一パルスの測距精度そのものが上がるわけではなく、「点群の密度が上がることで、結果としての空間的再現精度や統計的精度が向上する」**という意味です。

ここには「精度」の定義の違いが関わってきます。

---

### 「精度」の2つの意味を区別する

#### 1. 単一パルスの測距精度（距離分解能）

これは**1回のレーザー発射・受信で得られる距離値の正確さ**です。主に以下で決まります。

| 要因 | 典型的な値 |
|------|-----------|
| パルス幅 | 1nsなら空間的に約30cmの幅 |
| TDC（計時回路）の分解能 | 1psなら距離で約0.15mm |
| 受信回路のSN比 | 反射光の強度・ノイズ |

この単一パルスの測距精度は、**パルスレート（PRF）と基本的に無関係**です。むしろパルスレートを上げると1パルスあたりのレーザーエネルギーが減るため、受信信号のSN比が悪化し、単一パルスの精度が**低下する可能性**すらあります。

#### 2. 点群全体としての再現精度（メーカーが謳う「精度」）

メーカーがパルスレートと結びつけて語るのは、こちらの精度です。つまり**「広い範囲をどれだけ細かく、どれだけ正確に再現できるか」**という精度です。

---

### なぜパルスレートが高いと「精度が良くなる」のか

#### 理由1：点間距離が短くなり、地形の細部を捉えられる

航空機が秒速100mで飛行している場合を考えます。

| PRF | パルス間隔（時間） | 地上での点間距離（概算） |
|-----|------------------|------------------------|
| 50 kHz | 20 μs | 約2.0 m |
| 200 kHz | 5 μs | 約0.5 m |
| 1 MHz | 1 μs | 約0.1 m |

PRFが20倍になると、同じ飛行速度でも**点間距離が1/20**になります。これにより、以下のような細部が捉えられるようになります。

- 建物の稜線や角
- 道路の縁石
- 電柱や標識のような細い構造物
- 谷の急な斜面変化

**「点が密であればあるほど、実際の地形と点群の形状が一致する」**ため、結果として「精度が良い」と表現されます。

#### 理由2：統計的ノイズ低減が可能になる

高密度の点群では、**近接する複数点の値を平均化**できます。

```
1m間隔の点群:  1点しかない → その点の誤差がそのまま反映される
10cm間隔の点群: 100点ある → 平均すればランダム誤差は1/10に低減
```

ランダム誤差（タイミングジッター、大気の揺らぎなど）は統計的に平均化されるため、点密度が高いほど**フィルタリング後の精度が向上**します。

#### 理由3：複数回波の検出確率が上がる

樹冠や市街地では、1本のレーザーパルスが複数の反射面で反射します。PRFが高いと、**同じXY位置に近い場所に複数のパルスが当たる確率が上がり**、地面への到達パルス（最終回波）が増えます。結果として、樹冠下の地面標高をより正確に推定できるようになります。

#### 理由4：走査線間の隙間が埋まる

航空機LiDARでは、ミラーの走査で横断方向の線を描き、航空機の前進で次の線を描きます。PRFが低いと、走査線の間に**データの空白（隙間）**が生じます。

PRFが高いと、同じ走査線上に点が密集し、隣接する走査線とも重なり合うようになるため、**連続的な地形表面**が再現できます。これは特に急斜面や谷の稜線で重要です。

---

### ただし、パルスレートを上げると生じるトレードオフ

メーカーが「PRFが高いほど精度が良い」と謳っても、無制限に上げれば良いわけではありません。

| トレードオフ | 内容 |
|------------|------|
| **レンジアンビギュイティ** | 前のパルスの反射が戻る前に次を発射すると、距離が曖昧になる |
| **1パルスあたりのエネルギー低下** | 高PRFではパルス幅を短くするか出力を抑える必要があり、遠距離・低反射面での受信が困難に |
| **データ量の増大** | 処理・保存・配信の負荷が増える |
| **単一パルスのSN比悪化** | エネルギー密度低下により、ノイズに埋もれる可能性 |

つまり、メーカーの「高PRF＝高精度」という謳い文句は、**「適切な距離範囲・反射条件のもとで、高密度点群による空間的・統計的精度向上」**という前提条件が付いているのです。

---

### まとめ

| 精度の種類 | PRFとの関係 | メーカーの謳い文句の対象 |
|-----------|-----------|----------------------|
| **単一パルスの測距精度** | ほぼ無関係（むしろ悪化の可能性） | × |
| **点群の空間分解能** | PRFが高いほど向上 | ○ |
| **統計的ノイズ低減後の精度** | PRFが高いほど向上 | ○ |
| **複数回波・地面検出率** | PRFが高いほど向上 | ○ |

メーカーが「パルスレートが高いほど精度が良い」と謳うのは、**単一パルスの性能ではなく、最終的に得られる点群データセットとしての品質・再現性**を指しています。これは「カメラの画素数が高いほど写真が高精細になる」と言うのと同じ構造で、1画素の品質ではなく、画像全体の情報量と再現性の話です。

その通りです。実は**距離精度の本質的な誤差源は、まさに「発射時刻と受光時刻の記録精度」にあります**。

---

### 距離精度の誤差源は「時間記録の精度」

距離は以下で計算されます。

```
D = c × Δt / 2
c ≈ 299,792,458 m/s（光速）
```

光速は約**30cm/ナノ秒（1ns）**です。つまり、

| 時間誤差 | 距離誤差 |
|---------|---------|
| 1 ns（十億分の1秒） | 約 15 cm |
| 10 ps（百億分の1秒） | 約 1.5 mm |
| 1 ps | 約 0.15 mm |

**時間を1ナノ秒（1ns）間違えれば、距離が15cmずれます**。人間の感覚では瞬間でも、距離計測では大きな誤差になります。

---

### 時間記録にどんな誤差が入るのか

LiDAR内部では、**TDC（Time-to-Digital Converter）**という回路が「発射時刻 t₁」と「受光時刻 t₂」を記録します。このTDCには主に2種類の誤差があります。

#### 1. 分解能（Resolution）の誤差

TDCが時間を刻む最小単位です。例えば分解能が100psのTDCなら、

```
100ps × 30cm/ns ÷ 2 = 約 1.5cm
```

これは**量子化誤差**で、常に±分解能/2の範囲で揺らぎます。分解能を上げる（psレベルにする）には、より高速なクロックや補間回路が必要になり、回路設計が複雑・高価になります。

#### 2. ジッター（Jitter）の誤差

同じ距離を何度も計測しても、記録される時間がばらつきます。このばらつきがジッターです。

```
理想的な時間差: 1000.000 ns
実際の測定:     1000.050 ns（+50ps）
               999.980 ns（-20ps）
               1000.120 ns（+120ps）
```

ジッターの主な原因は以下です。

| 原因 | 内容 |
|-----|------|
| **レーザー駆動回路の遅延揺らぎ** | 発光トリガーから実際の発光までの時間が毎回微妙に違う |
| **APD/SPADの応答揺らぎ** | 受光から電気信号出力までの時間が光強度・温度で変化 |
| **コンパレータの閾値通過揺らぎ** | 信号波形の立ち上がりで、ノイズが重なるとトリガー時刻がずれる |
| **クロック源の位相ノイズ** | TDCの基準クロック自体が揺らぐ |
| **電源ノイズ・温度変化** | 回路定数が温度や電源電圧で変化 |

---

### なぜ「受光時刻」が特に問題なのか

発射時刻は**「自分で制御した時刻」**なので、比較的安定しています。一方、受光時刻は**「外から来た微弱な光を検出した時刻」**で、以下の問題があります。

#### 歩幅誤差（Walk Error）

反射光が強いとAPDの出力波形が大きく・早く立ち上がり、閾値を早く超えます。反射光が弱いと立ち上がりが遅く、閾値を遅く超えます。

```
強い反射光: 波形が急で大きい → 閾値を早く通過 → 受光時刻が「早く」記録される
弱い反射光: 波形が緩やかで小さい → 閾値を遅く通過 → 受光時刻が「遅く」記録される
```

同じ距離でも反射強度が変わると、**数十cmの距離誤差**が生じることがあります。これを防ぐため、**定時刻判別回路（CFD: Constant Fraction Discriminator）**などが使われます。

#### ノイズによる誤検出

受信回路には常にノイズ（熱雑音、背景光）が乗っています。信号が弱いと、**ノイズのピークが偶然閾値を超えてしまい、実際より早い時刻が記録される**ことがあります。これを**「虚警報（False Alarm）」**と呼びます。

逆に、信号がノイズに埋もれて閾値を超えないと、**受光時刻が記録されない（ミスディテクション）**こともあります。

---

### パルスレート（PRF）はこの時間誤差にどう関係するか

ここが重要です。

#### 原理的には「無関係」

TDCの分解能やジッターは、**回路設計と部品性能で決まります**。1秒間に1発撃とうが100万発撃とうが、1発あたりの時間記録精度は同じです。

#### しかし実際の装置では「間接的に関係する」

高PRF化のために装置設計を変更すると、時間記録精度に影響が出ます。

| 高PRF化による設計変更 | 時間精度への影響 |
|-------------------|--------------|
| 1パルスあたりのエネルギー低下 | 反射光が弱くなり、SN比が悪化 → ジッター増加 |
| 受信信帯域の拡大 | 熱ノイズが増加 → ジッター増加 |
| レーザー駆動の高速化 | 駆動回路の立ち上がりが急になり、過渡応答でジッター増加の可能性 |
| パルス幅の短縮 | 波形が急になり、閾値検出の精度が向上 → ジッター減少の可能性 |

つまり、**「PRFを上げたから時間精度が変わる」のではなく、「PRFを上げるために装置を改造した結果、時間精度が変わる」**のです。

---

### まとめ

| 項目 | 内容 |
|-----|------|
| **距離精度の本質的な誤差源** | 「発射時刻」と「受光時刻」の記録精度（TDCの分解能・ジッター） |
| **1nsの時間誤差** | 約15cmの距離誤差に相当 |
| **ジッターの主な原因** | 回路応答の揺らぎ、ノイズ、温度、反射強度（歩幅誤差） |
| **受光時刻が特に問題な理由** | 外からの微弱信号を検出するため、ノイズと反射強度の影響を受けやすい |
| **PRFとの関係** | 原理的には無関係。高PRF化の設計変更が間接的に影響する |

ご指摘の通り、**「時間をどれだけ正確に記録できるか」こそがLiDARの距離精度の核心**です。パルスレートは「どれだけ頻繁に記録できるか」の話で、「1回の記録がどれだけ正確か」とは別次元の問題です。ただし、高PRF機種ではその設計変更によって、時間記録精度が向上することもあれば低下することもある、というのが正確な理解になります。
