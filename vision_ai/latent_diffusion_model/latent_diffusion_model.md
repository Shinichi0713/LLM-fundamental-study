## 拡散潜在モデルとは

### 核心アイデア

画像そのものにノイズを加えて学習するのではなく、**画像を圧縮した「潜在表現」にノイズを加えて学習する**拡散モデルです。Stable Diffusion がこの方式を採用しています。

### 直感的な例え

**ピクセル空間の拡散モデル**（DALL-E 2 など）とは：
- 1000×1000ピクセルの巨大なキャンバスに直接ペンキ（ノイズ）を塗って消す練習をする
- キャンバスが巨大なので、計算コストが高い

**拡散潜在モデル**（Stable Diffusion など）とは：
- まず画像を**縮小図（潜在表現）**に変換
- 縮小図に対してノイズ除去の練習をする
- 最後に縮小図を元のサイズに拡大して復元

### 仕組み（3ステップ）

| ステップ | 内容 |
|---------|------|
| **1. エンコード** | 画像 → **VAE（変分自己符号化器）** で潜在空間に圧縮（通常 64×64×4） |
| **2. 拡散・学習** | 潜在表現にノイズを加え、U-Net がノイズを予測・除去するよう学習 |
| **3. デコード** | ノイズ除去後の潜在表現 → VAE で元の画像サイズに復元 |

```
[元画像 512×512×3] 
      ↓ VAEエンコード
[潜在表現 64×64×4]  ← ここで拡散処理（計算量が大幅削減）
      ↓ VAEデコード
[生成画像 512×512×3]
```

### なぜ「潜在（Latent）」なのか

[潜在空間](https://yoshishinnze.hatenablog.com/entry/2026/04/10/050000)とは、**人間には直接見えない、圧縮された情報の空間**のことです。

- VAE が画像の本質的な特徴（形・色・構造）を低次元のベクトルに変換
- 潜在空間では、似た画像同士が近くに配置される（「猫」の潜在表現は近い位置に集まる）
- ノイズ除去をこの空間で行うことで、**計算効率**と**品質**の両立を実現

### 通常の拡散モデルとの違い

| 項目 | 通常の拡散モデル | 拡散潜在モデル |
|------|---------------|--------------|
| **処理空間** | ピクセル空間（直接） | 潜在空間（圧縮後） |
| **計算コスト** | 高い（高解像度画像を直接扱う） | 低い（64×64程度で処理） |
| **メモリ** | 多い | 少ない |
| **学習速度** | 遅い | 速い |
| **代表例** | DALL-E 2, Imagen | **Stable Diffusion** |

### 注意点：「潜在」は「潜在変数モデル（VAE）」と同じではない

混同しやすい点です：

- **VAE（変分自己符号化器）** → 画像を潜在空間に圧縮・復元する道具
- **拡散モデル** → ノイズからデータを生成する道具
- **拡散潜在モデル** → **VAEで圧縮 → 拡散モデルで生成 → VAEで復元** と2つの技術を組み合わせたもの

つまり「VAEの潜在空間を拡散モデルが使っている」という関係です。

## 計算コストが低くなる理由

### 核心：「処理するデータのサイズ」が桁違いに小さい

拡散モデルの計算コストは、主に **U-Net 内の自己注意機構（Self-Attention）** で決まります。この計算量は**テンソルのサイズの2乗に比例**します。

### 具体的な数字で比較

512×512ピクセルの画像を生成する場合：

| 処理空間 | テンソルサイズ | 自己注意の計算量（ざっくり） |
|---------|-------------|------------------------|
| **ピクセル空間**（通常の拡散） | 512×512 = **262,144** ピクセル | ~262,144² ≈ **680億** 回の演算 |
| **潜在空間**（拡散潜在モデル） | 64×64 = **4,096** 潜在ベクトル | ~4,096² ≈ **1,700万** 回の演算 |

**約400分の1**の計算量で済みます。

### なぜ Self-Attention の計算量がサイズの2乗になるのか

Self-Attention は「すべてのピクセル（または潜在ベクトル）が、他のすべてと関係を計算する」仕組みです。

```
ピクセル1 ↔ ピクセル2, ピクセル3, ... ピクセルN
ピクセル2 ↔ ピクセル1, ピクセル3, ... ピクセルN
...
ピクセルN ↔ ピクセル1, ピクセル2, ... ピクセルN-1
```

N 個の要素があると、関係の組み合わせは N × N = N² になります。

| 空間 | N（要素数） | N² |
|------|-----------|-----|
| ピクセル空間 | 262,144 | ~680億 |
| 潜在空間 | 4,096 | ~1,700万 |


### 例え：学校のクラスで比べる

**ピクセル空間**＝全校生徒（500人）が互いに名札を交換する
- 1人が499人と交換 → 500×499 ≈ **25万回**の交換

**潜在空間**＝クラス代表（25人）が互いに名札を交換する
- 1人が24人と交換 → 25×24 = **600回**の交換

代表（潜在表現）同士で関係を整理してから、後で各クラス内（VAEデコード）で展開すれば、全体の作業量が劇的に減ります。

### VAE のコストはなぜ無視できるのか

VAE（エンコード・デコード）は畳み込み層で構成されており、Self-Attention のような「全要素同士の組み合わせ計算」を行いません。畳み込みは局所的な処理なので計算量が少なく、拡散ステップの数千回の反復と比べれば**ごくわずか**です。

| 処理 | 回数 | 計算量の目安 |
|------|------|------------|
| VAE エンコード | 1回 | 小さい |
| 拡散ステップ（U-Net） | 20〜50回 × 各ステップでSelf-Attention | **圧倒的に大きい** |
| VAE デコード | 1回 | 小さい |
