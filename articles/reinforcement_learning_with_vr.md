近年のLLMはSFTと呼ばれる教師あり学習を行った後、最近のモデルはRLVRと呼ばれるLLMの強化学習を行っています。
このRLVRについて解説していきたいと思います。

## RLVRとは
RLVR は **Reinforcement Learning with Verifiable Rewards**（検証可能報酬による強化学習）の略です。LLM の推論能力を強化学習で鍛える手法の一種で、特に DeepSeek-R1 や SofT-GRPO などで使われています。

### RLVR の基本構造

RLVR は以下の流れで動作します。

1. **質問を与える**: 例えば「2+3×4は？」のような数学問題
2. **モデルが回答を生成**: Chain-of-Thought（思考過程）を含めて回答
3. **報酬を計算**: 生成された回答が**正解かどうかを自動的に検証**し、正解なら +1、不正解なら 0（またはペナルティ）
4. **方策を更新**: 正解に導いた思考パターンの生成確率を上げ、不正解の確率を下げる

### RLVR の具体例

| タスク | 検証方法 |
|--------|----------|
| **数学問題** | 最終答えを数式エンジンで計算し一致確認 |
| **プログラミング** | コードを実行してテストケースをパスするか確認 |
| **論理パズル** | 論理式の充足性を自動検証 |
| **単位換算** | 次元解析で正否を判定 |

## RLVRがなぜ必要か？

RLVR が登場する前の LLM 学習と、RLVR 以降の学習を対比すると、その重要性が明確になります。

### 当時（RLVR 以前）の学習の限界

RLVR 以前、LLM の能力向上は主に以下の2段階に依存していました。

#### 1. 教師あり微調整（SFT）：「人間の模範解答を模倣する」
- 人間が「質問 → 正しい思考過程 → 回答」を大量に書き、モデルに模倣させる
- **問題**: 複雑な数学・論理問題では、人間でも正しい思考過程を書ききれない。間違った推論を教えてしまうリスクもある
- **問題**: 訓練データにない解法をモデルは発見できない。人間の能力が天井になる

#### 2. RLHF：「人間が好きそうな回答を選ぶ」
- 人間が「回答Aの方がBより良い」と比較ラベルを付け、報酬モデルを学習
- **問題**: 報酬の基準が主観的。「丁寧に見える」「自信満々に見える」回答に高スコアがつきやすい
- **問題**: 数学の正解よりも「人間が納得しそうな言い訳」が報酬を得やすく、**ハルシネーションをごまかす戦略**を学んでしまう恐れがある

### RLVR 以降の変化：「正解かどうか」で自動的に鍛える

RLVR は「正解が機械的に検証できる問題（数学・コード・論理など）」に対して、**人間のラベルなしに「正解に至る思考パターン」を試行錯誤で発見・強化**します。

| | **RLVR 以前（SFT / RLHF）** | **RLVR 以降** |
|---|---|---|
| **学習の材料** | 人間が書いた模範解答 | 正解が分かる問題セット + 自動検証器 |
| **最適化の対象** | 「人間らしい回答」「好ましい回答」 | **「正解かどうか」という客観的事実** |
| **思考過程の質** | 人間の思考の模倣に依存 | モデル自身が「正解に導く思考パターン」を探索・獲得 |
| **限界** | 人間の教師データの質と量 | 探索空間と検証器の精度 |
| **ハルシネーション** | ごまかせば報酬を得られる可能性 | 正解でなければ報酬が得られないため、正しい推論しか強化されない |

### なぜ RLVR は欠かせないのか

#### 1. 人間の教師データの「天井」を突破できる
SFT では人間が書ける解法しか学べませんでしたが、RLVR ではモデルが**訓練データにない新しい解法**を発見しても、正解なら報酬を得て強化されます。人間の能力を超える推論パターンの獲得が可能になります。

#### 2. 客観的な報酬が「正しい推論」のみを強化する
[RLHF](https://yoshishinnze.hatenablog.com/entry/2025/12/31/082922) では「説得力のある間違い」が高評価を得ることがありましたが、RLVR では**正解でなければ報酬が出ません**。これにより、モデルは「正しい推論を組み立てる」ことしか報酬を得られず、ハルシネーションを抑制しながら推論能力を高められます。

#### 3. 思考過程（Chain-of-Thought）自体を最適化できる
RLVR は最終回答の正否だけを見て、思考過程に対して報酬を伝搬させます。これにより、**「人間が書いた思考過程」の模倣ではなく、「正解に至るための最適な思考過程」**が強化学習を通じて形成されます。

#### 4. スケールする
人間の比較ラベルは高コストですが、RLVR では**プログラムで正解判定できる問題なら無限に学習データを増やせます**。数学問題やプログラミング課題は自動採点できるため、大規模な試行錯誤が可能になります。

## RLVRの基本的な仕組み

RLVR（Reinforcement Learning with Verifiable Rewards）の基本的な仕組みは、**「正解かどうかをプログラムで自動判定できる問題」を使い、LLM が自分で試行錯誤しながら「正解に導く思考パターン」を学ぶ**というものです。

以下、ロジックを順を追って説明します。

### 1. 3つの登場人物

| 要素 | 役割 |
|------|------|
| **LLM（方策）** | 質問に対して思考過程（CoT）と回答を生成する |
| **検証器（Verifier）** | 生成された回答が正解かを自動で判定する（プログラム・数式エンジンなど） |
| **学習アルゴリズム** | 正解だった思考パターンを強化し、不正解を弱める |

### 2. 1ステップの流れ

```
【入力】質問 Q（例：「1+2+3+...+10は？」）

    ↓

【生成】LLMが複数パターンの思考過程＋回答を生成
        パターンA：「1+2=3, 3+3=6 ... 」→ 回答「55」
        パターンB：「10×11/2=...」→ 回答「55」
        パターンC：「適当に足す」→ 回答「48」

    ↓

【検証】Verifierが各回答を判定
        パターンA：正解（+1）
        パターンB：正解（+1）
        パターンC：不正解（0）

    ↓

【更新】正解に導いた思考パターン（A, B）の生成確率を上げる
        不正解だったパターン（C）の生成確率を下げる
```


### 3. なぜ「思考過程」まで強化されるのか

ポイントは、報酬は**最終回答の正否**だけを見ることです。

- 最終回答が正解だった場合、その回答に至る**一連のトークン（思考過程全体）** に対して報酬を分配
- これにより、モデルは「どのような思考の流れが正解に繋がったか」を学習
- 結果として、**正解に導く推論の型**が自然と強化される

### 4. グループ相対評価（GRPO の場合）

SofT-GRPO などで使われる [GRPO](https://yoshishinnze.hatenablog.com/entry/2026/10/12/043000) 方式では、1つの質問に対して**複数の回答パターン（グループ）** を一度に生成します。

```
質問Qに対して16個の回答を生成
→ 正解が10個、不正解が6個
→ 正解群（10個）の思考パターンを強化
→ 不正解群（6個）の思考パターンを抑制
```

これにより、「この質問に対してはこの思考パターンが有効」という相対的な優劣から学習が進みます。

### 5. ロジックの核心

RLVR の本質は以下の2点です。

**① 報酬の客観性**
- 「正解か不正解か」は人間の好みではなく、プログラムで機械的に判定できる
- 曖昧な評価ではなく、明確な信号で学習が進む

**② 探索による発見**
- モデルは人間が書いた模範解答を模倣するのではなく、自分で様々な思考パターンを試す
- 正解に至った新しい解法が自動的に強化されるため、**人間の教師データにない推論パターン**も獲得できる

## RLVRの効果

RLVR の効果は、**「正解かどうか」という客観的な報酬信号によって、モデルの推論能力を根底から鍛える**ことにあります。RLHF と対比すると、その効果がより明確に見えてきます。


### 効果①：推論の「正しさ」を直接学習できる

| | **RLHF** | **RLVR** |
|---|---|---|
| **報酬の根拠** | 「人間が好きそう」「丁寧そう」「自信ありそう」 | **「答えが合っているか」** |
| **学習の結果** | 人間を納得させる話術が磨かれる | 正解に至る論理的思考が磨かれる |

**具体例**：数学問題「365 × 24 は？」

- **RLHF**：「自信満々に間違えた回答」でも、丁寧に説明していれば高評価を得られる可能性がある
- **RLVR**：答えが 8,760 でなければ報酬は出ない。途中計算のどこかが間違っていれば、最終的に正解に至らないため強化されない

つまり RLVR は **「ごまかしが通用しない環境」** で学習させるため、論理的な正しさそのものが鍛えられます。


### 効果②：ハルシネーション（虚偽情報）を抑制する

| | **RLHF** | **RLVR** |
|---|---|---|
| **ハルシネーションへの報酬** | 「説得力がある」なら誤情報でも高評価のリスク | **正解でなければ報酬ゼロ** |
| **学習の方向性** | 「信じさせる力」が強化される可能性 | 「正しく導く力」しか強化されない |

RLHF では「自信満々に嘘をつく」回答が、人間の評価者を納得させて高スコアを得ることがありました。RLVR では**正解かどうかしか判定されない**ため、モデルは「正しい情報に基づいて正解に至る」以外に報酬を得る道がありません。

### 効果③：人間の「模範解答の天井」を突破する

| | **RLHF / SFT** | **RLVR** |
|---|---|---|
| **学習の上限** | 人間が書いた解答の質が天井 | **モデル自身が新しい解法を発見・強化** |
| **新しい解法** | 訓練データにない解法は学べない | 正解なら自動的に強化される |

**具体例**：複雑な数学証明

- SFT/RLHF では「人間が書いた証明パターン」の模倣が限界
- RLVR では、モデルが思いついた**訓練データにない独創的な解法**でも、正解なら報酬を得て強化される

これにより、人間の教師データを超えた推論能力の獲得が可能になります。

### 効果④：スケールしやすい（大量の試行錯誤が可能）

| | **RLHF** | **RLVR** |
|---|---|---|
| **コスト** | 人間による比較ラベルが必要で高コスト | 自動検証なので**事実上無限にスケール可能** |
| **学習量** | ラベル予算に依存 | 計算リソースが許せば大量の問題で学習可能 |

RLHF は「人間が回答AとBを比較してラベル付け」する必要があるため、数万〜数十万ペアが限界です。RLVR は**プログラムで正解判定**するため、数百万〜数億の問題を自動的に生成・検証して学習できます。


### 効果⑤：思考過程（Chain-of-Thought）の質が向上する

RLVR は最終回答の正否を報酬としますが、その報酬は**思考過程全体に伝搬**します。

- 正解に至った思考過程の各ステップが強化される
- 不正解に至った思考過程は抑制される

結果として、**「人間が書いた模範的な思考」の模倣ではなく、「正解に導く実用的な思考パターン」** が形成されます。RLHF では「人間が読んで納得する思考過程」が優遇されますが、RLVR では **「論理的に正しい思考過程」** しか生き残れません。

## 総括

RLVR の本質は、**「正解かどうかをプログラムで自動判定できる問題」を使い、人間の教師データなしに LLM が自力で「正解に導く思考パターン」を発見・強化する強化学習**です。

### なぜ従来の学習では足りなかったか

| 従来の手法 | 限界 |
|-----------|------|
| **SFT（教師あり学習）** | 人間が書いた模範解答の模倣に依存。人間の能力が天井になり、訓練データにない新しい解法は学べない |
| **RLHF** | 報酬が「人間が好きそうかどうか」という主観的な評価。自信満々な間違いやハルシネーションが高評価を得るリスクがある |

### RLVR の本質的な違い

**「正解か不正解か」という客観的・機械的な報酬だけで学習する**

- 数学なら数式エンジン、コードならテスト実行、論理なら充足性検査で自動判定
- 人間の好みや「説得力」は関係なく、**答えが合っていなければ報酬は出ない**
- モデルは複数の思考パターンを試行錯誤し、正解に至った推論だけが強化される


### これがもたらす3つの本質的効果

1. **ハルシネーションの抑制**
   正解でなければ報酬が得られないため、「自信満々な嘘」や「ごまかし」が学習される余地がない。論理的な正しさだけが生き残る。

2. **人間の天井を突破**
   人間が書いた模範解答にない解法でも、正解なら自動的に強化される。モデルが人間を超える推論パターンを自力で発見できる。

3. **無限にスケールする**
   人間のラベルが不要なので、自動検証できる問題を使えば理論上無限に試行錯誤が可能。計算リソースが許す限り、大量の問題で推論能力を鍛えられる。


### 一言でまとめると

RLVR は **「正解の客観的検証」を報酬信号にすることで、LLM に「人間を納得させる力」ではなく「正解に論理的に到達する力」を、人間の教師なしに自力で獲得させる学習パラダイム**です。
