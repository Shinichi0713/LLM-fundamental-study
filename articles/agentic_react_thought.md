ReActパターンは、**LLM（大規模言語モデル）に「推論」と「行動」を交互に繰り返させる**ことで、自律的にタスクを解決させるフレームワークです。2022年にGoogle ResearchのYaoらによって論文「ReAct: Synergizing Reasoning and Acting in Language Models」で提案されました。[Google Research](https://react-lm.github.io/) [IBM](https://www.ibm.com/jp-ja/think/topics/react-agent)


## 1. ReActとは何の略か

**Re**asoning（推論）+ **Act**ing（行動）の合成語です。

| 要素 | 意味 | 役割 |
|---|---|---|
| **Reasoning（推論）** | 「今どんな状況か」「次に何をすべきか」を言語で考える | 計画の立案・状況の分析 |
| **Acting（行動）** | 検索、計算、ファイル読み込み、API呼び出しなどのツール実行 | 外部世界への働きかけ |


## 2. 3つの構成要素とループ構造

ReActパターンは、**思考 → 行動 → 観察**の3ステップを繰り返すループです。

```
┌─────────────────────────────────────────┐
│  Step 1: Thought（思考）                 │
│  「ファイルの内容を確認する必要がある」    │
└─────────────┬───────────────────────────┘
              ▼
┌─────────────────────────────────────────┐
│  Step 1: Action（行動）                  │
│  read_file("sample.txt") を実行           │
└─────────────┬───────────────────────────┘
              ▼
┌─────────────────────────────────────────┐
│  Step 1: Observation（観察）            │
│  「これはサンプルファイルです...」         │
└─────────────┬───────────────────────────┘
              ▼
┌─────────────────────────────────────────┐
│  Step 2: Thought（思考）                 │
│  「ファイルは読めた。次は時刻を確認する」  │
└─────────────┬───────────────────────────┘
              ▼
           ...繰り返し...
              ▼
┌─────────────────────────────────────────┐
│  Step N: Thought                         │
│  「必要な情報が揃った。タスク完了」        │
│  → Action: finish                       │
└─────────────────────────────────────────┘
```

### 各要素の役割

| 要素 | 内容 | なぜ必要か |
|---|---|---|
| **Thought** | LLMが「今の状況」と「次の方針」を自然言語で記述 | 推論過程を明示化し、行動の根拠を持たせる |
| **Action** | ツール名と引数を指定して実行 | 外部情報や計算能力にアクセスする |
| **Observation** | ツール実行の結果を受け取る | 新しい情報を次の思考に反映させる |


## 3. ReActが生まれた背景：CoTの限界

ReAct以前には**Chain-of-Thought（CoT）**という手法がありました。CoTは「途中の考え方を出力しながら答えを導く」ものですが、**LLMの内部知識のみに依存**するため、以下の問題がありました。

| 手法 | 推論 | 外部情報の利用 | 問題 |
|---|---|---|---|
| **CoTのみ** | できる | できない | 最新情報や外部データにアクセスできない |
| **Actingのみ** | ない | できる | なぜその行動を選んだか分からない |
| **ReAct** | できる | できる | 推論と行動を統合し、相互に補完 |

ReActは、**「考えること」と「道具を使うこと」を交互につなぐ**ことで、CoTの限界を克服しました。[TRAIL](https://thetrail.jp/research/react-reasoning-and-acting/) [Zenn](https://zenn.dev/tech_taka/articles/d81db2f45268f0)



## 4. 実際のLLMプロンプトの例

ReActパターンでは、LLMに以下のような形式で出力させます。

```
目標: オリンピックでコオロギの100m記録を持つ種は？

思考: コオロギの100m記録について知る必要がある。
      まず検索で確認する。

行動: search["コオロギ 100m 記録 オリンピック"]

観察: コオロギの100m記録は正式なオリンピック種目ではないが、
      研究によるとアレクサンドリア・コオロギは秒速約1.5mで
      100m換算で約66秒という記録がある。

思考: オリンピック種目ではないことが分かった。
      正式なオリンピックの陸上100m記録と比較して回答する。

行動: search["オリンピック 陸上 100m 世界記録"]

観察: 男子100mの世界記録はウサイン・ボルトの9.58秒（2009年）。

思考: コオロギの記録（換算66秒）と人間の世界記録（9.58秒）
      を比較して回答をまとめる。

行動: finish["コオロギの100m記録は正式なオリンピック種目では
      ありませんが、研究によるとアレクサンドリア・コオロギは
      100m換算で約66秒。人間の世界記録（9.58秒）より大幅に
      遅いです。"]
```

## 5. ReActの効果：論文の実験結果

原論文では、ReActを他の手法と比較した実験が行われています。[Google Research](https://research.google/blog/react-synergizing-reasoning-and-acting-in-language-models/)

| タスク | ReActの優位性 |
|---|---|
| **質問応答（HotpotQA）** | CoTのみやActingのみより高い正答率 |
| **対話的な環境（ALFWorld, WebShop）** | 推論の助けを借りて行動することで、行動だけより高い成功率 |

ただし、**すべてのタスクでReActが最優**というわけではありません。単純なタスクでは、推論ステップを省略した方が速い場合もあります。[issoh](https://www.issoh.co.jp/tech/details/16312/)


## 6. ReActと他のパターンの違い

| パターン | 特徴 | 使い分け |
|---|---|---|
| **ReAct** | 思考と行動を**交互に**繰り返す | 情報が不足していて、調べながら進める必要があるタスク |
| **Plan-and-Execute** | 最初に計画を立てて、順に実行 | 手順が予測可能で、計画が安定するタスク |
| **Reflexion** | 失敗を自己批判し、再試行する | 試行錯誤が必要で、反省から学ぶタスク |
| **Tree of Thoughts** | 複数の思考パスを分岐探索 | 探索空間が広く、最適解を探す必要があるタスク |

[AIgent Lab](https://aigentlab.tech/articles/ai-agent-reasoning-planning-patterns-react-reflexion-2026/)


## 7. なぜReActが現代のAIエージェントの基盤になったのか

ReActが広く採用されている理由は、以下の3点に集約されます。

### 1. 推論と行動の相乗効果

推論が行動を導き、行動の結果が次の推論を豊かにする。**「考える」ことと「動く」ことが相互に補完**します。

### 2. 人間の問題解決プロセスに近い

人間も「考えて、調べて、結果を見て、また考える」を繰り返します。ReActはこの**自然な認知プロセスをLLMに模倣**させています。

### 3. デバッグしやすい

LLMが「なぜその行動を選んだか」をThoughtとして明示的に出力するため、**エージェントの判断プロセスを人間が追跡・検証できる**。[zeroentropy](https://zeroentropy.dev/concepts/react-prompting/)


## まとめ

> **ReActパターンは、LLMに「思考（Reasoning）→ 行動（Acting）→ 観察（Observation）」のループを繰り返させ、自律的にタスクを解決させるフレームワーク。**  
> 推論と行動を統合することで、LLMの内部知識だけでは解けない問題や、外部情報が必要な問題に対処できるようになりました。

先ほどお渡ししたPython版・C++版のコードは、このReActパターンを**最小構成で実装**したものです。実際のLLMでは、Thought部分を自然言語で生成させることで、より柔軟で高度な自律動作を実現しています。
