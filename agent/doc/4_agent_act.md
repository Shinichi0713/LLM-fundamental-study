ReActパターンの仕組みは、**「思考 → 行動 → 観察」**の3ステップを**目標が達成されるまで繰り返す**ループ構造です。先ほどのコードを使って、具体的に追っていきます。

---

## ReActパターンの基本構造

```
┌─────────────────────────────────────┐
│  目標: 「sample.txtの内容を読んで、  │
│         現在時刻も教えて」            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 1: 思考（Thought）              │
│  「ファイルの内容を確認する必要が    │
│    ある」                            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 1: 行動（Action）               │
│  read_file("sample.txt") を実行      │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 1: 観察（Observation）         │
│  「これはサンプルファイルです。       │
│    AIエージェントのテスト用データ。」 │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 2: 思考（Thought）              │
│  「ファイル内容は読めた。            │
│    次は現在時刻を確認する必要がある」 │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 2: 行動（Action）               │
│  get_time() を実行                   │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 2: 観察（Observation）         │
│  「2026-11-15 14:32:10」            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  Step 3: 思考（Thought）              │
│  「必要な情報が揃った。              │
│    タスクを完了する」                │
└──────────────┬──────────────────────┘
               ▼
          ✅ 完了
```

## コードでの具体的な動作

### 1. 思考（Thought）：`think()` メソッド

```python
def think(self, goal: str) -> str:
    # 目標に含まれるキーワードを分析
    # 「ファイル」という言葉がある → read_fileが必要
    # まだ実行していない → 次の行動は read_file
    return '{"thought": "ファイルの内容を確認する必要があります", 
             "action": "read_file", 
             "action_input": "sample.txt"}'
```

エージェントは、**「今どんな状況か」「次に何をすべきか」**を自分で考えます。実際のLLMでは「思考」を自然言語で生成しますが、このサンプルコードではキーワードマッチングでシミュレートしています。

---

### 2. 行動（Action）：ツールの実行

```python
# parse_action() で思考から行動を抽出
action, action_input, thought = self.parse_action(thought_json)
# → action="read_file", action_input="sample.txt"

# TOOLS辞書から対応する関数を取得して実行
observation = TOOLS["read_file"]("sample.txt")
# → "これはサンプルファイルです。\nAIエージェントのテスト用データ。\n"
```

エージェントは**実際にツールを使って何かを実行**します。これがReActの「Act（行動）」部分です。

---

### 3. 観察（Observation）：結果をメモリに記録

```python
self.memory.append(f"Step1: read_file(sample.txt) -> これはサンプルファイルです...")
```

行動の結果（観察）は**メモリに保存**されます。次のステップの「思考」では、このメモリを参照して「もうファイルは読んだから、次は時刻を確認しよう」と判断できます。

## なぜこのループが重要なのか

| 要素 | 役割 | なぜ必要か |
|---|---|---|
| **思考（Thought）** | 現在の状況分析と次の行動計画 | 単なるツール呼び出しではなく、「なぜこのツールを使うか」の推論を明示化 |
| **行動（Action）** | ツールの実際の実行 | 外部世界（ファイル、計算、APIなど）に働きかける |
| **観察（Observation）** | 行動結果の記録と次への反映 | 1回の行動で得た情報を、次の思考に活かすため |

## 実際のLLMとの連携では

このサンプルコードでは思考部分をキーワードマッチングで代用していますが、実際のLLM（ChatGPTやGeminiなど）を使う場合は以下のようになります。

```
【LLMへの入力】
目標: sample.txtの内容を読んで、現在時刻も教えて
利用可能なツール: read_file, get_time, calculator
これまでの履歴: （まだなし）

【LLMの出力】
思考: ファイルの内容を確認する必要があります
行動: read_file("sample.txt")

【LLMへの入力】（観察結果を追加）
目標: sample.txtの内容を読んで、現在時刻も教えて
これまでの履歴:
  Step1: read_file("sample.txt") → 「これはサンプルファイルです...」

【LLMの出力】
思考: ファイル内容は確認できた。次に現在時刻を確認する
行動: get_time()
```

LLMは**これまでの観察結果を文脈として受け取り**、次の行動を決定します。これが「コンテキスト管理」として以前お話ししたCompactionの対象になる部分です。

## まとめ

ReActパターンの本質は、**「考えてから動き、結果を見てまた考える」**という**人間の問題解決プロセスをAIに模倣**したものです。

- **思考なしの行動**：目的もなくツールを叩くだけの自動化
- **行動なしの思考**：実際に何も実行しない空想
- **観察なしのループ**：前回の結果を無視して同じことを繰り返す

この3つが揃うことで、初めて**自律的に目標に向かって進むエージェント**が成立します。
